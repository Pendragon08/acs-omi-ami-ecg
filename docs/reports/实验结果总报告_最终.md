# ACS 亚型三分类与 OMI 二分类联合任务：实验结果总报告

**更新时间：** 2026-08-31
**报告状态：** 当前有效代码和结果已完成仓库清理与完整性审计。

## 1. 最终结论

当前任务由两个相关但不同的输出组成：

1. **ACS 亚型单标签三分类**：只在 ACS 阳性样本中区分 `STEMI / NSTEMI / UA`，
   三类互斥，使用 softmax 和 argmax，不使用三个独立阈值；
2. **OMI/NOMI 二分类**：与 ACS 亚型维度独立，使用 sigmoid；OMI 工作阈值由内部
   验证数据选择。

全队列训练时保留 `[0,0,0]` 的明确 non-ACS 样本。现有一阶段模型因此内部使用
`OTHER / STEMI / NSTEMI / UA` 四状态 softmax 头；`OTHER` 只是训练时的 non-ACS
状态，**不是第四种 ACS 亚型**。最终 ACS 临床任务仍按 ACS 阳性三分类报告。

综合内部患者级五折 OOF、外部平台 hard-label 指标和训练成本，当前工程推荐方案为
**ECG-LFM LoRA**（rank=8、alpha=16、dropout=0.05、学习率 `1e-4`）。其主要内部
验证结果为：

| 任务 | 指标 | 结果 |
|---|---|---:|
| ACS 阳性三分类 | Accuracy | 0.8058 |
| ACS 阳性三分类 | Macro-F1 | 0.6541 |
| OMI 二分类 | AUROC | 0.9106 |
| OMI 二分类 | AUPRC | 0.4315 |
| OMI 二分类（Youden，阈值 0.05） | Sensitivity / Specificity | 0.8549 / 0.8359 |
| OMI 二分类（Youden，阈值 0.05） | PPV / NPV / F1 / MCC / Accuracy | 0.2629 / 0.9883 / 0.4021 / 0.4165 / 0.8371 |

该推荐是**探索性工程选择**，不是统计显著的确认性临床结论。当前只有一个训练种子
（seed=2026）的固定患者级五折；外折同时参与 checkpoint 选择，pooled OOF 又参与
OMI 阈值选择。外部平台也已被多种模型反复查看并参与选型，因此不能再称为完全未触碰的
独立确认性测试集。

  一个互斥标签。
- ECG-LFM 使用官方 500 Hz 输入契约；每条记录由两个片段推理后平均 logits。
- GitHub 不保存原始 ECG、患者级表格、checkpoint、逐例预测或平台提交 CSV。

内部标签目前通过 `y_all.npy` 的位置索引与主记录表对齐，并有数组、记录清单、fold、
checkpoint 的 SHA-256 及患者不交叉检查。后续确认性实验仍应增加带 record ID 的标签
清单并按 ID 显式 join，进一步消除位置错配风险。

## 3. 模型与训练方案

### 3.1 ECG-LFM

三种方案使用相同的预训练 ECG-LFM 主体、输入流程、联合分类头、batch size 64、
`update_freq=4`、Adam、step 学习率调度和 patience=10。登记学习率分别为：

| 方案 | 适配方式 | 学习率 |
|---|---|---:|
| Baseline | 卷积特征前端冻结，其余主体及分类头进行部分/有效微调 | 1e-6 |
| LoRA | rank=8，alpha=16，dropout=0.05 | 1e-4 |
| DoRA | rank=8，alpha=16，dropout=0.05 | 5e-5 |

Baseline 配置中 `feature_grad_mult=0.0`，卷积特征前端在 `torch.no_grad()` 下运行，
因此它不是字面意义的“所有参数全量微调”。LoRA/DoRA 与 Baseline 的学习率不同，结果
只能解释为“适配方法及其登记学习率”的联合比较，不能把全部增益纯粹归因于适配器结构。

### 3.2 其他对比模型

- E4：Xception 形态专家、导联空间专家、端到端 WavelNet 频域专家、task router 和
  KAN head；没有使用 MVMD 作为网络外部预处理。
- 传统模型：InceptionTime、ResNet1D-Wang、LSTM、ViT-1D、Transformer1D。

## 4. 内部患者级五折 OOF 对比

ACS 列只统计 ACS 阳性样本的互斥三分类；OMI 使用每个模型在 pooled OOF 上选出的
Youden 工作点。ACS 不使用 Youden 阈值，因为单标签多分类由一个 softmax argmax 决策，
不存在三个可独立调整且仍保持互斥的二分类阈值。

| InceptionTime | 0.7938 | 0.6280 | 0.8911 | 0.3999 | 0.8358 | 0.8089 | 0.3613 |
| ResNet1D-Wang | 0.7974 | 0.6187 | 0.8915 | 0.4010 | 0.8384 | 0.8059 | 0.3589 |

| Transformer1D | 0.7813 | 0.6078 | 0.8732 | 0.3623 | 0.7976 | 0.7915 | 0.3294 |
| ECG-LFM Baseline | 0.8055 | 0.6439 | 0.9052 | 0.4159 | 0.8488 | 0.8228 | 0.3826 |

LoRA 相对 Baseline：ACS Accuracy `+0.0003`、Macro-F1 `+0.0102`；OMI AUROC
`+0.0054`、AUPRC `+0.0157`、Sensitivity `+0.0061`、Specificity `+0.0131`、
F1 `+0.0195`。DoRA 的 ACS Accuracy 和 OMI Youden F1 略高，但 LoRA 在 ACS
Macro-F1、OMI AUROC/AUPRC 及外部四个 one-vs-rest F1 的平均值上更好，且训练成本更低。

### 4.1 LoRA 的 ACS 三分类详细结果

三类逐类指标是对同一个三分类 argmax 结果做 one-vs-rest 展开，便于观察各亚型难点；
它们不是三个独立二分类器。

| 类别 | Sensitivity | Specificity | PPV | NPV | F1 | MCC | Accuracy |
|---|---:|---:|---:|---:|---:|---:|---:|
| STEMI | 0.6963 | 0.9506 | 0.7318 | 0.9417 | 0.7136 | 0.6600 | 0.9093 |
| NSTEMI | 0.2899 | 0.9416 | 0.4447 | 0.8915 | 0.3510 | 0.2790 | 0.8511 |
| UA | 0.9338 | 0.6597 | 0.8643 | 0.8112 | 0.8977 | 0.6332 | 0.8513 |

三分类混淆矩阵（行是真值，列是预测；顺序 STEMI/NSTEMI/UA）：

```text
[[1004, 188,  250],
 [ 216, 358,  661],
 [ 152, 259, 5802]]
```

由该混淆矩阵得到整体 Accuracy `0.8058`、Macro-F1 `0.6541`；NSTEMI 的低
Sensitivity 是当前最主要的 ACS 亚型瓶颈。

本次代码审计发现旧版 `acs_subtype_metrics` 曾用 argmax 后的硬指示量计算所谓逐类
AUROC/AUPRC。该实现已改为使用 ACS 三类条件归一化的连续概率。由于历史 checkpoint
尚未按修正后的函数重新导出，当前总报告不引用旧的逐类或 Macro AUROC/AUPRC 数值。

## 9. 完整性审计与适用边界

本次 same-family 独立只读审计的当前结论为 **WARN / provisional**：旧错误任务已清除，
当前建模与主要汇总值可信，但证据仍是探索性的。

- 未发现伪造真值、自归一化预测分数或在本地读取外部隐藏标签。
- 当前内部 OOF 是真实标签评价，但 checkpoint 选择和阈值选择没有嵌套验证，硬指标偏乐观。
- 当前只有一个训练种子，五折不等于五个独立随机种子；尚无方法间统计显著性结论。
- 平台结果已经参与模型选择，不能继续称为 untouched confirmatory test。
- 外部平台只有聚合 JSON，未在 Git 中保留提交 CSV、逐例预测或原始响应，以满足数据安全规则。
- Sensitivity≥0.90/0.95 的阈值搜索若无可行点，必须明确标记 `infeasible`，不能将退化结果
  命名为对应敏感度工作点。

若要发表确认性结论，建议冻结当前 LoRA 方案，增加 outer-train 内的 patient-level inner
split 用于 checkpoint 和阈值选择，使用多个独立种子，并在一个从未参与选型的外部队列上
只评价一次。
