# ECG-LFM ACS 四状态分类与 OMI 二分类联合任务：实验结果总报告

**更新时间：** 2026-09-01

**当前版本：** nested validation、W0–W6、校准与单任务对照已更新

**当前推荐方案：** ECG-LFM LoRA Joint W0（未加权 CE + 未加权 BCE）

> 本报告是 GitHub 当前正式实验结果入口。旧的 pooled OOF、传统模型和外部平台结果保留为历史证据；当前方法选择以严格 patient-level nested Fold0 对照为准。所有指标均注明 validation 类型，不混用 pooled OOF、nested outer-test 与外部平台结果。

## 1. 当前任务定义

当前模型是一个联合多任务模型，而不是四个独立 sigmoid 标签：

1. **ACS Head：互斥四状态单标签分类**
   - `OTHER / STEMI / NSTEMI / UA`；
   - 4 logits；
   - `CrossEntropyLoss + Softmax`；
   - hard prediction 使用 `argmax`，不对四个类别分别调阈值。
2. **OMI Head：独立二分类**
   - `OMI / NOMI`；
   - 1 logit；
   - `BCEWithLogitsLoss + Sigmoid`；
   - threshold 仅在 inner-validation 选择，冻结后用于 outer-test。

全队列保留明确的 `[0,0,0]` non-ACS 样本并标为 `OTHER`。真实 ACS 病例可额外报告条件三分类：

`P(k|ACS) = P(k) / [P(STEMI)+P(NSTEMI)+P(UA)]`。

OMI 与 ACS 状态是两个不同维度，不能把 OMI 并入 ACS softmax，也不能对全部 5 个 logits 做一次 softmax。

## 3. 当前模型与训练策略

- 预训练主体：ECG-LFM；
- 表征维度：pooled 1024-D；
- 联合输出层：`Linear(1024, 5)`，前 4 个 logits 属于 ACS，最后 1 个属于 OMI；
- 微调：LoRA rank 8、alpha 16、dropout 0.05；
- 学习率：`1e-4`；
- 联合目标：`L = L_ACS + 1.0 × L_OMI`；
- W0 的训练 loss：未加权 CE + 未加权 BCE；
- 当前训练参数：5,903,365 / 628,779,269，约 0.9389%；
- checkpoint：未加权 inner-validation CE+BCE 最小；
- early stopping patience：10。

## 5. 严格 nested Fold0：W0–W6 类别重加权实验

Primary endpoints 为 ACS Macro AUPRC、NSTEMI AUPRC 和 OMI AUPRC。所有组只改变训练阶段 loss weighting。

| 方法 | ACS Loss | OMI Loss | ACS Macro AUPRC | NSTEMI AUPRC | OMI AUPRC |
|---|---|---|---:|---:|---:|
| **W0** | Unweighted CE | Unweighted BCE | **0.546685** | **0.287459** | **0.412660** |
| W1 | Static weighted CE | Unweighted BCE | 0.530770 | 0.279219 | 0.409730 |
| W2 | Unweighted CE | Static pos-weight BCE | 0.517696 | 0.247335 | 0.381572 |
| W3 | Static weighted CE | Static pos-weight BCE | 0.495348 | 0.240624 | 0.361160 |
| W4 | RDR-CE | Unweighted BCE | 0.534947 | 0.263176 | 0.388518 |
| W5 | Unweighted CE | RDR-BCE | 0.534947 | 0.263176 | 0.388518 |
| W6 | RDR-CE | RDR-BCE | 0.534947 | 0.263176 | 0.388518 |

### 5.1 结论

- 静态类别加权 W1–W3 均未超过 W0；
- W6 相对 W0：ACS Macro AUPRC `−0.011738`、NSTEMI AUPRC `−0.024283`、OMI AUPRC `−0.024142`；
- W4/W5/W6 在 warmup 后确实启用了 RDR，但最终最佳 checkpoint 都停留在未体现 RDR 收益的 warmup 阶段，最终 predictions 完全一致；
- RDR 未通过预注册 Fold0 gate，因此按照方案停止，没有启动 W0–W6 完整五折、多 seed 或 paired bootstrap；
- 当前结论是 **RDR NO-GO**，只说明本研究中的 inverse-frequency static weighting 与当前 RDR 适配没有获益，不能泛化为所有类别不平衡方法都无效。

`results/loss_feature_ablation/` 中的 Weighted BCE、Focal、CB-Focal、年龄、性别和中位数 ECG 实验属于旧 OMI/AMI 二分类端点，不是当前 ACS 四状态 + OMI 联合任务的公平消融，不能用于证明当前联合模型中的对应方法有效或无效。

当前联合任务已经公平验证的是 W0–W6 Fold0。旧消融保留用于方法学溯源，但不参与当前最终方案选型。

## 11. 当前结论

1. 评估概率语义和 record-ID provenance 已修复；
2. 当前严格 nested Fold0 最佳方法是 **ECG-LFM LoRA Joint W0**；
3. 静态权重和 RDR 在当前 Fold0 均未超过未加权 W0；
4. W0 校准后概率质量改善；
5. Joint 在 Fold0 同时优于 ACS-only 与 OMI-only，呈现正迁移；
6. NSTEMI 仍是主要瓶颈，W0 的 NSTEMI AUPRC 为 0.287459、Sensitivity 为 0.240816；
7. 当前没有进入 RL 的科学必要性，RL 仍为 NO-GO；
8. 下一项最有价值的实验，是将 ACS-only / OMI-only / Joint W0 扩展为完整 outer 5-fold，验证正迁移是否稳定，而不是继续 RDR 或实现 RL。
