# ACS–OMI ECG 实验结果总报告（最终整理版）

**更新时间：** 2026-09-05

**当前研究任务：** ACS–OMI Joint-6 六分类

**当前最佳 Joint-6 模型：** ECG-LFM + LoRA

**证据范围：** 内部 patient-level nested 5-fold；逐 ECG 评价；尚无当前 Joint-6 独立外部测试

## 1. 当前任务与数据

当前主任务使用单一 6-way Softmax 与 CrossEntropyLoss：

1. `OTHER`
2. `STEMI+nOMI`
3. `STEMI+OMI`
4. `NSTEMI+nOMI`
5. `NSTEMI+OMI`
6. `UA`

从联合概率恢复 ACS 四分类：`[q0, q1+q2, q3+q4, q5]`；恢复 OMI 概率：`q2+q4`。ACS 使用 argmax；OMI 阈值仅在 inner-validation 上通过 Youden Index 确定并冻结到 outer-test。

- 训练池：17,960 条 ECG、17,018 名患者；
- outer patient-level 5-fold，seed=2026；
- 每个 outer-train 内建立 patient-level inner-train/inner-validation；
- Joint-6 support：OTHER 9,070、STEMI+nOMI 715、STEMI+OMI 727、NSTEMI+nOMI 812、NSTEMI+OMI 423、UA 6,213；
- raw OMI 阳性 1,151 条；唯一 `OTHER+OMI` 不删除，训练时映射为 OTHER，但保留原始 OMI 标签参与 OMI 主评价。

## 7. 其他消融与优化结论

### 7.1 静态类别权重与 RDR（严格 nested Fold0）

W0 未加权 LoRA 的 ACS Macro AUPRC、NSTEMI AUPRC、OMI AUPRC 分别为 0.546685、0.287459、0.412660。W6 RDR 相对 W0 分别变化 -0.011738、-0.024283、-0.024142；因此当前 RDR 适配为 NO-GO。该结果不证明所有类别不平衡方法均失效。

### 7.2 单任务与联合学习（严格 nested Fold0）

Joint W0 相比 single-task：ACS Macro AUPRC +0.007147、NSTEMI AUPRC +0.017178、OMI AUPRC +0.054021。结果支持方向性正迁移，但只有一折，不能宣称跨折稳定或统计显著。

### 7.3 多目标优化与 RL

- linear sum、PCGrad、CAGrad、FairGrad、Aligned-MTL 均未通过 Stage-A gate；
- Direct RL 的 ACS、NSTEMI、OMI AUPRC 均低于 W0；
- R1-v2 四个 Head-only 候选均 Safety PASS，但最佳 clinical utility 仍低于 W0；
- Cross-task RL v2 outer Fold0 仅有 ACS AUPRC +0.000070、OMI AUPRC +0.000156，同时 OMI F1 -0.001746、utility -0.000921。

因此现阶段没有证据证明 RL 或多目标优化优于监督基线，不应作为已验证 contribution。

## 8. 旧双 Head 结果与任务方案比较边界

旧 factorized LoRA 的修正 pooled OOF 结果为 ACS Macro AUPRC 0.5390、OMI AUPRC 0.4315；Joint-6 pooled 约为 0.5405、0.4200。两组使用的 checkpoint 选择与 validation protocol 不完全相同，不能据此断言 Joint-6 优于或劣于双 Head。当前可以严谨声明的是：

- Joint-6 是当前选择并完整运行的任务形式；
- ECG-LFM LoRA 是 Joint-6 七种对照中的最佳模型；
- Joint-6 相对 factorized two-head 的严格同协议优势尚未建立。

## 9. 外部测试状态

当前 Joint-6 尚未提交独立外部测试平台。仓库中早期 external/platform 指标属于旧端点或旧工程流程，只能作为历史记录，不能冒充当前 Joint-6 外部验证结果。

## 10. 最终结论与下一步

1. 当前完整主结果是 35/35 folds 的 Joint-6 模型对比；ECG-LFM LoRA 综合最好。
2. 最主要短板是 `NSTEMI+OMI` 和 `NSTEMI+nOMI`，尤其前者 sensitivity 仅 0.0536 ± 0.0373。
3. LoRA 在保持最佳综合性能的同时显著降低可训练参数与显存，具备明确工程价值。
4. 暂不能把 Joint-6 优于双 Head、RDR、MOO 或 RL 写成已证明的方法创新。
5. 下一项最有价值的实验是：在完全相同 nested splits、初始化、LoRA 和训练配置下，严格重跑 factorized two-head 与 Joint-6，并进行 patient-level paired bootstrap；冻结唯一方案后再做独立外部测试。
