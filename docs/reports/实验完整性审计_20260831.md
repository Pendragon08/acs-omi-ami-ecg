# 实验完整性审计（2026-08-31）

**总体结论：WARN（可继续研究，当前证据仅限探索性）**

**审阅独立性：same-family**

**接受状态：provisional**

本次审计由新的只读审阅代理复核当前代码、结果 JSON、报告引用和评价流程。初审在清理前
判定为 FAIL；旧错误任务、失效路径和两处评价代码问题修复后，当前结论降为 WARN。

## A. Ground truth 来源：WARN

- 内部 OOF 使用真实训练标签，患者级五折无患者交叉，OOF 完整且不重复。
- `y_all.npy`、主记录表、每折 manifest 和 checkpoint 均记录 SHA-256。
- 外部本地推理不读取隐藏标签，平台返回隐藏真值的聚合指标。
- 剩余风险：内部标签仍主要依赖数组位置与记录索引对齐，没有带 record ID 的标签清单
  逐 ID join；现有哈希能证明文件身份，不能单独证明每一行身份。

## B. 分数与阈值：WARN

- AUROC/AUPRC 直接使用 softmax/sigmoid 连续概率，未发现按模型自身最大值、均值等进行
  自归一化。
- ACS 亚型旧指标函数曾使用 argmax 硬指示量计算 AUROC/AUPRC，现已改为 ACS 阳性条件下
  归一化的三类连续概率；历史错误 AUC 不再进入当前总报告。
- Sens90/Sens95 若无可行阈值，后续代码输出 `threshold=null`、`status=infeasible`，
  不再返回伪工作点。
- pooled OOF 同时用于 OMI 阈值选择和硬指标计算，故硬指标是描述性的，不是嵌套验证估计。

## D. 失效代码与旧任务：PASS（清理后）

- 已删除把 STEMI/NSTEMI/UA 当作三个独立 sigmoid 的旧配置、训练器、阈值脚本、平台
  提交链路、结果目录和报告。
- 已删除失效/重复的 ECG-LFM 首轮与 local-best 入口，只保留当前 joint runner。
- `acs_utils/metrics.py` 已明确标为历史 OMI/AMI 消融专用，不作为当前联合任务入口。
- 所有删除内容仍可由 Git 历史恢复，但不应回到当前结果发现路径。

## E. 结论范围：WARN

- 当前校正任务只有一个训练 seed=2026；五折不是五个独立随机种子。
- 每折外折验证集还参与最佳 checkpoint 选择；OMI pooled OOF 又参与阈值选择。
- 外部平台结果已被 E4、传统模型和三种 ECG-LFM 多次查看并参与最终 LoRA 选型，
  已不再是 untouched confirmatory test。
- LoRA、DoRA 与 Baseline 的登记学习率不同，不能将性能差异完全归因于适配器结构。
- 因此可以给出工程推荐，不能声称统计显著、独立外部临床验证或临床泛化已成立。

## F. 评价类型

| 管线 | 类型 | 限制 |
|---|---|---|
| 内部患者级 OOF | `real_gt` | checkpoint/阈值非嵌套选择，描述性 |
| 外部本地推理 | `inference_only` | 不读取隐藏标签 |
| 外部平台 JSON | `platform-hidden real_gt` | 已参与模型选择，仅作描述性证据 |
| 历史 OMI/AMI 消融 | `real_gt`，其他端点 | 不能证明当前联合任务性能 |

## 清理后的接受标准

当前代码和结果可以继续作为探索性研究基础。形成论文确认性结论前，应：

1. 使用 record ID 显式连接标签与记录；
2. 在每个 outer-train 内增加 patient-level inner split，选择 checkpoint 和阈值；
3. 增加多个独立随机种子并做配对统计比较；
4. 冻结方案后，在未参与任何选型的新外部队列上只评价一次。
